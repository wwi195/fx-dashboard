# 累積損益・通貨ペア別スワップ込み・金額欄の検知 設計書

作成日: 2026-11-05

## 1. 累積損益グラフと最大ドローダウン

- 「日別推移」のタブに「累積」を追加する。
- 線は「スワップ込み」と「トレード損益のみ」の2本。点は決済日ごとの最終値。
- サマリーに「最大ドローダウン」を追加する。
- 最大ドローダウンは、スワップ込みの累積を決済日時順に1件ずつ計算し、それまでの最高値からの最大下落幅とする。
  最高値の初期値は期間開始時の0円。
- どちらも上部の期間フィルタに連動し、選択期間の開始時点を0円として数える。
- 記録されるのは決済時の確定額のみなので、保有中の含み損益は含まない。

## 2. 通貨ペア×方向のスワップ込み表示

- 「通貨ペア × 方向」に「損益」と「スワップ込み」の切替タブを追加する。初期表示は「損益」。
- スワップ込みでは、グラフの値を損益＋スワップにし、一覧にスワップ額も表示する。
- 勝率は切替に関わらず損益のみで計算する（元の設計書の5節に従う）。

## 3. 金額欄の記入ミス検知

`parseAmount` を次の場合に失敗扱いにする。失敗した記録は集計から除外し、「要確認」と表示する（既存の動作）。

- 使える文字以外を含む。使えるのは半角数字、`.`、`+`、`＋`、`-`、丸括弧（半角・全角）、`スワップ`、`円`、空白。
  カンマ、全角数字、`−`、`▲`、`マイナス`、`手数料` などはここで検知する。
- `-` の直後が数字でない（`25470-スワップ2055`、`25470 - 2055`）。
- `スワップ` と書いてあるのに数値が1つしかない（`25470+スワップ`）。

既存の記入形式はすべて従来どおり読み取る。
