# 心のチェック 設計

作成日：2026-11-20（Discordでユーザーと合意）

## 目的
エントリーするか迷ったとき、または決済後のインターバル（±1万円以内→1時間、±2万円→2時間。ユーザーが自分で守る）が明けたときに、
「エントリーするに値する平常さがあるか」を自分で確かめる。自信があるときは使わない。

ユーザーの負けパターン：利益が出る → 余裕ができる → 雑なトレード・遊びのトレード。だから勝った後は追加の質問がある。

## 画面（check.html）
ダッシュボード上部の「🧘 心のチェック」から開く。1問ずつ表示。
1. 状況：迷っている／勝った後（インターバル明け）／負けた後（インターバル明け）
2. 3択の質問（🟢🟡🔴）。共通5問、勝った後は+3問。質問と選択肢は `check-logic.js` が正。
   - 体調だけ複数選択：良い・普通🟢／疲れている🟡／寝不足🔴／お酒が入っている🔴（良い・普通は他と同時に選べない）
3. 今の気持ちを一言で（必須、判定には使わない）
4. 判定（2026-11-24 変更）：🟢0点・🟡1点・🔴2点の合計で、0点→入ってOK／1点→1時間様子見（見るだけ）／2点→2時間休む／3点→4時間休む／4点→8時間休む／5点以上→今日はもうやめておこう。体調の寝不足・お酒は点数に関係なく今日はもうやめておこう
5. 行動を選ぶ。判定がOK以外で「それでも入る」なら理由を書かないと進めない
6. Googleフォーム「FX心のチェック」へ送信。まとめをコピーしてDiscordでClaudeと深掘りできる

## 記録
Googleフォーム「FX心のチェック」（回答はスプレッドシート「FX心のチェック（回答）」）に no-cors POST。
質問名 → entry番号は `config.js` の `CHECK_FORM_ENTRIES`。回答は「🟡 疲れている」のように色付きの文字で入る。聞いていない質問は空欄。
