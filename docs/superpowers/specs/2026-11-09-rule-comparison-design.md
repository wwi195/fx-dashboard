# ルール別の成績 設計メモ

作成日: 2026-11-09

## 目的

「根拠通りだったか」と「OCO通り決済か」の回答ごとに成績を並べ、ルールを守ったときと破ったときの差を金額で見えるようにする。

## 表示

- トレード一覧の上に「ルール別の成績（損益のみ）」欄を置く。期間フィルターに連動する。
- 質問ごとに、回答別の件数、勝率、平均損益、合計損益を表にする。
- 表の下に、YESとNOの平均損益の差を一文で示す。どちらかが0件なら差は出さない。
- 金額は損益のみとする。スワップは保有日数で決まり、ルールの守り方とは別の要因のため。
- OCO通りには損切り到達も含むことを注記する。

## 回答の判定

- OCO通り決済か: YES / NO / それ以外（不明）。
- 根拠通りだったか: 過去の記録は自由記述が多いため、書き出しで判定する。全角は半角にそろえる。
  - `yes` または `根拠通り` で始まる → YES
  - `no` で始まる（`none` などの英単語は除く） → NO
  - `不明` で始まる → 不明
  - それ以外 → 未分類
