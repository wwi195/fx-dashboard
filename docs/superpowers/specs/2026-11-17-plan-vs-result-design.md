# 計画と結果 設計メモ

作成日: 2026-11-17

## 目的

エントリー前に決めた利確と損切りの幅に対して、実際にどこで決済しているかを見えるようにする。利確が早すぎる、損切りが遅れているといった癖を数字でつかむ。

## 計画の読み取り

- 新しい記録は「利確pips」「損切pips」をそのまま使う。
- 過去の記録は、エントリー価格と利確価格・損切価格の差から求める（1pips = 0.01円）。
- 価格の後ろの「円」や、かっこ書きのメモは無視して先頭の数字を読む。
- 読めない、方向と逆、幅が300pipsを超える計画は、打ち間違いとみなして対象外にする。
- 結果のpipsは損益から逆算する（1ロット1pips = 100円）。OCO通り決済の記録で、計画の損切り幅と結果が一致することを実データで確認した。

## 表示

「計画と結果」欄を「ルール別の成績」の上に置き、期間フィルターに連動させる。

| 項目 | 内容 |
|---|---|
| 計画の利確幅 | 利確幅 ÷ 損切り幅の平均 |
| 実際の平均 | R（結果pips ÷ 損切り幅）の平均 |
| 勝ちの目標達成率 | 勝ちトレードの結果pips ÷ 利確幅の平均。目標の9割未満で利確した件数も示す |
| 負けの平均 | 負けトレードのRの平均。-1.1Rより大きく負けた件数を「損切りラインを超えた負け」として示す |

トレード一覧の詳細には「計画 → 結果」の行を加える（例: `利確+100 / 損切-50pips → +51.7pips（+1.03R）`）。

金額は損益のみとし、スワップは含めない。

## テスト

`test/aggregate.test.js` で、計画の読み取り（新旧、メモつき価格、不正な計画）、R、集計値、0件の扱いを検証する。
